# Original image generation

The exact complete prompt for each built-in image generation call is stored once in assets/manifest.json. It includes subject, physical construction, framing, lighting, exclusions and intended dimensions. No unavailable seed or model-version metadata has been invented.

A01, A02, A03, A04, A06, A07, A08, A09, A10, A11 and A12 form the original collection. T01 is the selected desktop visual target, T02 the mobile target, and T03 the exploded duct composition. The direction was already selected by the user, so no approval round or alternate concepts were required.

The collection uses believable contemporary UAE settings, neutral daylight, restrained stone, timber, fabric and brushed metal. No fabricated staff, clients, uniforms, brands, logos or certificates were generated.

The redesign adds seven scenario-specific originals. Exact prompts, the bounded carpet-extractor edit, actual dimensions and provenance are in assets/v2/manifest.json. All were generated with the built-in image tool, then inspected and optimized. The image set is used in the opening, service cards, detailed service use cases, hospitality and shared-surface scenarios.
